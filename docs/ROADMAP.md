# Roadmap

## Atual

- [x] Base Tauri 2 + Vue 3 + TypeScript.
- [x] Painel compacto de uso do Codex.
- [x] Bandeja, janela unica e ciclo de vida nativo.
- [x] Refresh manual e automatico com retencao de snapshot stale.
- [x] Cache local separado por conta Codex.
- [x] Login, polling e logout pelo fluxo local suportado.
- [x] Testes frontend e Rust, lint, typecheck e build Windows.

## Proximo

- [ ] Repetir a matriz manual em uma instalacao limpa.
- [ ] Validar distribuicao e instalacao final.
- [ ] Confirmar acessibilidade com teclado, leitor de tela e escalas comuns.
- [ ] Medir tempo de abertura, memoria e CPU com o painel aberto e oculto.

## Depois do uso real

- [ ] Polimento visual orientado por feedback.
- [ ] Instalador e atualizacao automatica.
- [ ] Avaliar um segundo provedor somente com uma fonte confiavel.

## Nao planejar agora

- Backend, telemetria ou sincronizacao.
- Sistema de plugins ou descoberta dinamica.
- Historico e graficos sem uma necessidade comprovada.
